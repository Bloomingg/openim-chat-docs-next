description: '设置其他用户添加当前账号时的申请处理方式。'

`addFriendPermission` 控制其他用户添加当前账号时，是否需要当前用户审批。它属于<span className="enterprise-field-badge">商业版</span>账号策略，不应与昵称、头像等普通资料一起保存。

```uts
import { setSelfInfo } from '@/uni_modules/unix-openim-sdk'

await setSelfInfo({
  addFriendPermission: 0,
})
```

| 数值 | 含义 |
| --- | --- |
| `0` | 允许发起好友申请，但需要当前用户审批。 |
| `1` | 允许直接建立好友关系，不需要当前用户审批。 |
| `2` | 不允许其他用户添加当前账号。 |

该设置只影响之后发生的加好友操作，不会删除已有好友，也不会自动处理待审批的申请。

Promise 成功表示更新请求完成，不等于 `onSelfInfoUpdated` 已经到达。事件监听和资料校准方式见[更新当前用户资料](/sdk/uniapp/user/profile/set-self-info)。
